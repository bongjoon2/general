# Open Source Project Health Checker

A lightweight open-source tool for checking basic health indicators of a software project.

## Features

- README availability check
- License availability check
- Issue tracking check
- Recent activity check
- Simple project health score

## Purpose

This project provides a simple starting point for developers who want to review the basic health and public-facing quality of an open-source repository.

## Project Status

Early-stage open-source project.

More checks and reporting features will be added over time.
